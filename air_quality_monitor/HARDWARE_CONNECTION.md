# ESP32 + STM32 空气质量监测系统 - 硬件连接指南

## 系统架构

```
[STM32F103] ←UART→ [ESP32] ←WiFi→ [互联网AQI API]
   ↓                    ↓
 OLED显示          数据处理+建议生成
 MQ135传感器
```

## 硬件连接

### UART 交叉连接

| STM32 引脚 | → | ESP32 引脚 | 说明 |
|-----------|---|-----------|------|
| USART1 TX (PA9) | → | GPIO16 (RX) | STM32 发送传感器数据 |
| USART1 RX (PA10) | ← | GPIO17 (TX) | ESP32 发送建议数据 |
| GND | ←→ | GND | **必须共地！** |

### ⚠️ 重要注意事项

1. **电平匹配**：STM32 和 ESP32 都使用 3.3V 逻辑电平，可以直接连接
2. **共地**：两个开发板的 GND 必须连接在一起
3. **交叉连接**：TX 接 RX，RX 接 TX（不要 TX 接 TX！）
4. **波特率**：115200 bps（两端已配置一致）

## 数据协议

### STM32 → ESP32（传感器数据）

格式：`MQ135:PPM=%.2f,TEMP=%.2f,HUMI=%.2f,AQI=%.2f,LEVEL=%s\r\n`

示例：
```
MQ135:PPM=450.25,TEMP=25.00,HUMI=50.00,AQI=450.25,LEVEL=Good\r\n
```

字段说明：
- `PPM`: CO2 浓度（来自 MQ135）
- `TEMP`: 温度（当前使用默认值 25°C，可添加 DHT11 传感器）
- `HUMI`: 湿度（当前使用默认值 50%，可添加 DHT11 传感器）
- `AQI`: 空气质量指数
- `LEVEL`: 空气质量等级（Excellent/Good/Moderate/Poor/Bad/Hazardous）

### ESP32 → STM32（建议数据）

格式：纯文本建议，以 `\r\n` 结尾

示例：
```
室内空气质量(优)优于室外(良)。建议：关闭门窗，使用空气净化器保持室内空气质量。注意：室内空气质量不佳，敏感人群应减少活动。\r\n
```

## 工作流程

1. **STM32 端**（每 2 秒）：
   - 读取 MQ135 传感器数据
   - 在 OLED 上显示实时数据
   - 通过 UART 发送数据到 ESP32

2. **ESP32 端**：
   - 从互联网获取室外 AQI 数据（每 10 分钟）
   - 接收 STM32 发送的室内传感器数据
   - 计算室内 AQI 并与室外对比
   - 生成健康建议并发送回 STM32

3. **STM32 接收建议**：
   - 通过 UART 中断接收 ESP32 的建议
   - 在 OLED 上显示建议信息

## 引脚配置

### STM32F103
- **USART1 TX**: PA9
- **USART1 RX**: PA10
- **MQ135 ADC**: PA0 (ADC1 Channel 0)
- **OLED I2C**: PB6 (SCL), PB7 (SDA)

### ESP32
- **UART1 TX**: GPIO17
- **UART1 RX**: GPIO16
- **WiFi**: 内置

## 测试步骤

1. **分别测试**：
   - 先单独测试 STM32 项目（确认 MQ135 和 OLED 工作正常）
   - 再单独测试 ESP32 项目（确认 WiFi 和 AQI API 正常）

2. **连接测试**：
   - 连接 UART 线缆（注意交叉连接和共地）
   - 打开串口监视器查看 ESP32 日志
   - 观察 STM32 OLED 是否显示建议信息

3. **调试技巧**：
   - 使用 USB-TTL 模块监控 UART 通信
   - ESP32 日志会显示接收到的数据和解析结果
   - STM32 OLED 会显示传感器数据和建议

## 当前限制

1. **温湿度数据**：当前使用默认值（TEMP=25°C, HUMI=50%），建议添加 DHT11/DHT22 传感器
2. **AQI 计算**：室内 AQI 主要基于 MQ135 的 CO2 浓度，未包含 PM2.5 等其他指标
3. **API 密钥**：当前使用 demo 密钥，建议申请 waqi.info 的正式 API 密钥

## 改进建议

1. 添加 DHT11/DHT22 温湿度传感器到 STM32
2. 添加 PM2.5 传感器（如 PMS5003）以获得更准确的 AQI
3. 在 STM32 上添加 LED 指示灯显示空气质量状态
4. 实现数据校准机制（MQ135 需要定期校准 R0 值）
